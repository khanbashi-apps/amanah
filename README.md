# أمانة — ديونك وحقوقك بوضوح

تطبيق عربي لتنظيم الديون والسلفيات بين الأفراد: من سلّفته ومن تسلّفت منه، الأقساط الشهرية، سجل الدفعات، الإيصالات، وكشف حساب مربع يُرسل عبر واتساب.

- **نسخة الويب (PWA):** تعمل بدون إنترنت وتُضاف إلى الشاشة الرئيسية من Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».
- **نسخة الآيفون (IPA):** تُبنى تلقائياً على GitHub Actions مع كل تحديث، وتظهر في قسم Releases بدون توقيع (توقّعها بتطبيق التوقيع). فيها تنبيهات الأقساط والتطبيق مغلق، وزر «تم التسديد ✓» داخل التنبيه، و Face ID.
- البيانات محفوظة في جوال المستخدم فقط.

الإصدار الحالي: **v1.2**
